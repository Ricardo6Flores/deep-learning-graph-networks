# deep-learning-graph-networks
Redes neuronales convolucionales.
## Resumen
Este proyecto implementa dos aplicaciones principales de redes neuronales en grafos:

1. **Imputación de datos**: Reconstrucción de valores faltantes en nodos de grafos usando convoluciones espectrales basadas en polinomios de Chebyshev.
2. **Clasificación nodal**: Sistema de clasificación multi-clase aplicado a datasets académicos (Texas, Corar).
